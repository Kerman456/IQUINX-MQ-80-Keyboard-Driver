    关于

    这是一个为 IQUNIX MQ80（VID 0x320F / PID 0x5055） 编写的小型 VIA 兼容驱动，参考了 the-via/app 与 cebby2420/via-desktop 的实现方式。

    • 通过 WebHID 直接与键盘的 raw HID 接口（usage page 0xFF60）通信，无需额外驱动。
    • 支持多图层改键、灯光菜单、宏编辑，以及恢复出厂与进入 Bootloader。
    • 「演示模式」使用内存模拟设备，未插键盘也能体验完整界面。
    • 键码表按 VIA 协议版本自动选择（v9 / v10 / v11 / v12 / v13）。

    浏览器模式需要 Chrome / Edge（WebHID）。桌面版通过 Electron 封装，可离线使用。
